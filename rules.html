서버 규칙

Firebase 콘솔 → Realtime Database → 규칙 탭에 붙여넣는 글이에요. 붙여넣고 게시를 눌러야 적용돼요.

① 지금 붙어 있는 규칙을 확인하세요

규칙 탭에 있는 글에서 "members" 줄이 보이고 .validate가 많으면 엄격 버전, "rooms" 아래에 .read와 .write 두 줄뿐이면 간단 버전이에요. 모르겠으면 엄격 버전을 고르세요. (옛 방 규칙은 그대로 두고 새 규칙만 덧붙이는 거라, 어느 쪽을 골라도 지금 앱은 안 막혀요.)

② 아래 둘 중 하나를 통째로 복사해서 붙여넣기

엄격 버전 + 새 규칙 (추천)



간단 버전 + 새 규칙










③ (선택) 새 규칙 부분만 덧붙이고 싶을 때


기존 "rooms": { … } 블록이 끝나는 } 바로 뒤에 쉼표(,)를 붙이고, 아래 글에서 바깥쪽 중괄호를 뺀 "v2": { … } 부분만 붙여넣으세요. 쉼표를 빼먹으면 게시가 안 돼요.
